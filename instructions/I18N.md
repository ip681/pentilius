# PENTILIUS — Internationalization

## Requirement — LOCKED
Internationalization must be built in from the beginning.

English is the source language.

Start development with:
- `en`
- `bg`

Future languages may include:
- `de`
- `es`
- `fr`
- others.

## Rules
Never hard-code user-facing text in components.

Use translation keys.

Example:

```json
{
  "combat": {
    "attack": "Attack",
    "victory": "Victory"
  }
}
```

Bulgarian:

```json
{
  "combat": {
    "attack": "Атака",
    "victory": "Победа"
  }
}
```

## Dynamic content
Use placeholders:

```text
combat.damage_dealt
```

Example value:

```text
Damage dealt: {{amount}}
```

## Game definitions
Do not store English display text as the canonical identity of items/buildings/Pentili.

Prefer stable IDs and translation keys:

```text
item_id: plasma_cannon_t2
name_key: items.plasma_cannon_t2.name
description_key: items.plasma_cannon_t2.description
```

## Fallback
If a translation is missing, fall back to English.

## Do not translate
Normally keep these unchanged:
- Pentilius;
- player-created clan names;
- player names.

Final race-name translation policy is **UNDEFINED**.
